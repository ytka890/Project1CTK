### Описание системы
**"Контроль за деталями"** — это полноценное десктопное приложение, написанное на языке **Python** с использованием графической библиотеки **Tkinter** и обработкой графики через **Pillow**.

**Для чего это нужно:**
* Быстрый аудит имеющихся плат, датчиков и модулей в лаборатории.
* Исключение путаницы при передаче оборудования между сменами учителей.
* Оперативный контроль остатков ("В наличии", "Мало", "Отсутствует").

<summary><b>🔑 СЛАЙД 3: Доступ и аккаунты учителей</b></summary>
<br>

### Безопасность и авторизация
В систему встроены **5 защищенных учетных записей** для преподавателей Центра талантов. Каждому логину соответствует свой уникальный пароль:

| Логин (Учитель) | Пароль доступа | Назначение |
| :--- | :--- | :--- |
| **teacher1** | `CTKArduino` | Лаборатория Arduino |
| **teacher2** | `CTKESP32` | Интернет вещей (IoT) |
| **teacher3** | `CTKUnoNano` | Мобильная робототехника |
| **teacher4** | `CTKPlateS` | Конструирование |
| **teacher5** | `CTKMegaUnion` | Старшие группы (Mega) |

</details>

### Функционал приложения
* **🖼️ Загрузка реальных фото:** Преподаватель может загрузить изображение `.png` или `.jpg` с компьютера, программа автоматически адаптирует его под ячейку таблицы.
* **➕ Интерактивный счетчик:** Справа выведена удобная панель. Выделяйте деталь кнопкой мыши и изменяйте количество кнопками `+1` / `-1`.
* **🔄 Умные статусы:** Количество мгновенно пересчитывает статус. Если деталей 0 — статус автоматически горит как *"Отсутствует"*.

</details>
