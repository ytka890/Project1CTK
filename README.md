# 🛠️ Контроль за деталями
### Центр талантов "Кемерово"

Программа учета и контроля компонентов для преподавателей

---

## 📋 Описание проекта

**Контроль за деталями** — это десктопное приложение на Python (Tkinter), разработанное специально для учителей Центра талантов.

- **Цель:** Ведение оперативного учета плат, датчиков и робототехнических компонентов.
- **Интерфейс:** Стильная темная тема с динамическим фоном.

---

## 🔑 Доступ в систему

Для авторизации в системе используются 5 предустановленных аккаунтов преподавателей:

1. **teacher1** — `CTKArduino`
2. **teacher2** — `CTKESP32`
3. **teacher3** — `CTKUnoNano`
4. **teacher4** — `CTKPlateS`
5. **teacher5** — `CTKMegaUnion`

---

## 🚀 Основные возможности

- **Загрузка изображений:** Возможность прикреплять реальные фото деталей с компьютера.
- **Быстрый счетчик:** Изменение количества (+1 / -1) в один клик прямо из таблицы.
- **Умные статусы:** Автоматическое обновление статусов ("В наличии", "Мало", "Отсутствует").

---

## 💻 Технологии

Презентация создана на базе следующих библиотек:
- **Python 3.13 / 3.14**
- **Tkinter & TTK** (Графический интерфейс)
- **Pillow (PIL)** (Работа с изображениями и размытием)
