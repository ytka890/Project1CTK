🛠️ Контроль за деталями

Центр талантов "Кемерово"

Программа учета и контроля компонентов для преподавателей

(Для переключения используйте стрелки на клавиатуре или на экране)

📋 Описание проекта

"Контроль за деталями" — это десктопное приложение на языке Python с графическим интерфейсом Tkinter.

Программа разработана специально для преподавателей робототехники и электроники, чтобы быстро отслеживать состояние оборудования.

🔑 Доступ в систему

В систему вшиты 5 защищенных аккаунтов учителей для раздельного доступа:

  • teacher1 — пароль: CTKArduino
  • teacher2 — пароль: CTKESP32
  • teacher3 — пароль: CTKUnoNano
  • teacher4 — пароль: CTKPlateS
  • teacher5 — пароль: CTKMegaUnion

🚀 Ключевые возможности

  • 🖼️ Загрузка фото: Учитель может выбрать любое изображение (.png, .jpg) со своего ПК, программа сама сожмет его под размер таблицы.
  • ➕ Быстрый счетчик: Кнопки добавления (+1) и уменьшения (-1) количества детали в один клик.
  • 🔄 Авто-статус: Система сама ставит статус («В наличии», «Мало», «Отсутствует») на основе количества.

🎨 Премиальный дизайн

Интерфейс приложения адаптирован под современные стандарты программного обеспечения:

  • Экран входа: Адаптивный размытый фон с широкой полупрозрачной полосой.
  • Главный экран: Глубокие темно-графитовые тона (Dark Mode), снижающие нагрузку на глаза преподавателя во время работы.
